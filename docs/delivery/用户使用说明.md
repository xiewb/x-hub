# x-hub 用户使用说明（交付文档）

> 正本位置：`source/docs/delivery/`；上游完整功能介绍见 `source/README.md` 与 `source/docs/user-guide.md`。
> 本说明覆盖日常使用要点 + fork 增强功能。

## 1. 启动

双击 `runtime\bin\Run-App.cmd`（或 `x-hub.exe`）。首屏为**工作台**（Bento 网格）。

## 2. 核心模块速览

| 模块 | 说明 |
|---|---|
| 工作台 | Bento 网格自由编排：时钟（3 形态）、天气、资源监视、便签、日记、速记/待办/速达概览卡、提示词百宝箱、待办日历、倒计时列表、自定义速达 ×4；所见即所得布局编辑器，可存默认布局 |
| 倒计时 | 时长/定时/每天/间隔 4 模式（最多 6 个），到点系统通知，可浮起为水罐浮窗 |
| 速达 | 应用/网页/文件三合一，拖拽导入自动提图标，已在运行的程序调度前台而非重复启动；加密备注 |
| 速记 | Markdown 笔记（fork 大幅增强，见下） |
| 待办 | 清单 + 日历标注 |

## 3. 速记模块（fork 增强）

- **编辑器**：CodeMirror 6 源码模式（语法高亮/行号/查找替换 Ctrl+F·Ctrl+H/撤销重做/大纲导航）。
- **格式工具栏**：14 键通用工具栏；`==高亮==` 扩展语法；正文字符数统计。
- **标签**：全局删除（级联摘除）、筛选栏自动换行。
- **垃圾箱**：软删除 / 恢复 / 彻底删除 / 清空，均带确认。
- **搜索排序**：按标题/内容搜索；按修改时间/创建时间/名称/大小排序（持久化）。
- **预览**：源码 ↔ 实时预览 round-trip 无损，单换行不再放大为空行。

## 4. 数据与隐私

所有数据默认本地存储（SQLite + 本地文件），不上传云端；天气/名言卡片需联网，离线自动回退。

# x-hub 安装配置说明（交付文档）

> 正本位置：`source/docs/delivery/`（本文件）；交付副本：`runtime/doc/`
> 适用版本：fork v0.8.1（上游 v0.6.5 基点，已合并上游 v0.8.1）

## 1. 系统要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 1809+ / Windows 11 |
| WebView2 | 系统 WebView2 Runtime（Win11 自带；Win10 缺失时从 https://developer.microsoft.com/microsoft-edge/webview2/ 安装 Evergreen 版） |
| 磁盘 | 程序 ~15 MB + 本地数据（SQLite） |

## 2. 安装方式

### 2.1 便携版（本仓库五层交付形态）
1. 整个 `runtime\` 目录拷贝到目标机器任意位置（自包含，无需 source/build）。
2. 双击 `runtime\bin\Run-App.cmd` 或直接运行 `runtime\bin\x-hub.exe` 启动。
3. 无需安装器、无注册表写入、无管理员权限。

### 2.2 从源码构建
1. 安装 Node.js 20+、Rust 1.77+、Python（仅脚本）。
2. 在 `source\` 内 `npm install`。
3. 从 `build\bin\Build-App.ps1` 发起构建（产物落 `build\out\`，并自动同步 exe 到 `runtime\bin\`）。

## 3. 配置与数据

- 运行数据（SQLite 数据库、布局、localStorage 持久化项）位于系统用户数据目录（`%APPDATA%` 下应用目录），不上传云端。
- 运行日志：`runtime\log\`（由启动器重定向）。
- 卸载：删除 `runtime\` 目录与 `%APPDATA%` 下应用数据目录即可，无残留。

## 4. 常见问题

- **启动无窗口**：确认 WebView2 Runtime 已安装（见第 1 节）。
- **杀毒软件拦截**：未签名 exe，添加信任即可。
- **升级**：用新 `runtime\` 覆盖时保留或按需迁移 `%APPDATA%` 数据目录。
